A-Square Static Website
=======================

Files
-----
index.html
styles.css
script.js

Deployment
----------
Upload all three files to the public/root folder of a-square.com.sg hosting.
Typical folders are:
- public_html
- www
- htdocs

The website is fully static and does not require PHP, Node.js or a database.

Contact form
------------
The current contact form uses mailto: and opens the visitor's default email application.
Recipient: info@a-square.com.sg

To use a server-side form later, connect the form to your hosting provider's mail handler,
Formspree, Web3Forms, or your own API endpoint.

Before publishing
-----------------
1. Confirm info@a-square.com.sg is the correct public email address.
2. Replace or extend the company address/contact details if desired.
3. Add an official A-Square logo if available.
4. Add favicon / social sharing image if desired.
